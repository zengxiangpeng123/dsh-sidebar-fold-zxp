# 侧栏插件入口折叠 —— 设计（短）

日期：2026-10-28　|　规模：**小到中等**（纯客户端，无宿主部分）
状态：**已实现并验收**（2026-10-28，界面实测通过）

## 意图与原因

对话时，左栏顶部那排插件入口（插件 / 插件市场 / 自动化任务 / 上下文洞察 / 任务看板 / 使用统计 / 记忆系统 / 更多）每行约 46px，合计吃掉约 400px，把下面的**工作区与会话列表**压到只剩一点。要的是：**把那组入口折成一行，会话列表占满**。

## 目标

- 折起来时：那排入口只剩**一行**「插件 (7)」，其余空间全给会话列表
- 点那一行展开 / 折叠，状态记住
- 哪个面板正开着，就**让那一行保持可见**（否则用户不知道自己看的是哪个面板）
- 卸载后左栏完全恢复原样

## 非目标

- 不改会话列表本身，不做分组、不做文件夹
- 不改插件入口的图标、顺序、点击行为
- 不接管整个左列（不顶替 `sidebar` 槽）

## 反目标

- 靠猜 CSS 类名定位（类名带哈希，`bJOniG_panelList` 这种一升级就变）
- 折叠后把「当前打开的面板」也藏了
- 行列错位 / 出现第二个滚动条 / 折叠行长得不像原生行
- 插件被禁用或出错时把左栏弄坏（必须优雅退化成原样）

## 约束（已核实，非假设）

1. `sidebar.panellist` 是**列表槽**，只能追加自己的条目；没有隐藏他人的接口，`layout` 服务也没有 hide-panel 方法。
2. 外壳对那排入口**没有任何折叠/溢出逻辑**：`panels.map(...)`，有几个排几个。
3. 行的 DOM：`<nav aria-label="面板"><button aria-label={label}>…</button>…</nav>`，**行是 nav 的直接子元素**，且 nav 本身没有任何 `data-*` 钩子。
4. 我们自己的条目会被渲染进某个行的 `<span aria-hidden>` 里（外壳用 `renderSlot('sidebar.panellist', {size, active}, {only: id})`）。
5. 生态里已有先例：`dsh-settings-nav-organizer` 用**纯结构选择器** `[role="dialog"][aria-modal="true"] > nav > div:last-child` 折叠设置面板的第三方入口，不依赖类名。

## 方案（与之前的对比）

| 方案 | 做法 | 结论 |
|---|---|---|
| A 顶替整个 `sidebar` 槽 | 自己重画左列，只把 `sidebar.workspaces` 借回来 | 放弃：等于接管外壳外观，升级易碎 |
| B 猜类名隐藏行 | 注入 CSS 命中 `nav` 的类名 | 放弃：类名带哈希，一升级就废 |
| **C 自锚点折叠** | 注册自己的入口当锚点，从它反查 `nav`，按兄弟关系隐藏/显示 | **选中** |

## 已决定（我方裁定，可推翻）

1. **以自有条目为锚点**：`ourNode.closest('nav')` → `nav.querySelectorAll(':scope > button')`。不出现任何类名或全局选择器。
2. **我们的条目就是折叠开关**：在自有 glyph 上挂 `onClick` 并 `stopPropagation()`，阻止外壳的 `selectPanel(id)`（我们没有对应面板，不能被它切走）。行样式由外壳渲染，**天然和原生行一致**。
3. **折叠时保留两行**：我们的开关行 + 当前激活的行（读 `aria-current="page"`）。
4. **状态存在 `localStorage`**（`dsh-sidebar-fold:folded`），默认**折叠**——装它就是为了省空间。不新增宿主侧接口、不新增设置页。
5. **`MutationObserver` 监听 nav**，插件热装/卸载后重新套用；找不到 nav 或结构不符就**什么都不做**（优雅退化，绝不抛错）。
6. **不用 `display:none`，用 `hidden` 属性**，并同时设 `aria-hidden`，避免屏幕阅读器仍念出被折叠的行。

## 留给实现者

- 折叠行的计数文案（`插件 (7)` 里的 7 是 nav 里被折叠的行数，不含自己）
- 展开/折叠图标（`chevron` 方向）
- 首次安装默认折叠是否要让用户看到一次提示

## 验收

1. 折叠后：左栏只剩一行「插件 (7)」，下面工作区/会话列表立刻占满
2. 点它展开 → 8 行回来；再点 → 收起；刷新页面后状态还在
3. 打开「任务看板」再折叠 → 任务看板那一行**仍然可见**，其余被收起
4. 装一个新插件 → 折叠状态下它自动被折进去，计数 +1
5. 禁用本插件 → 左栏立刻恢复原样，无残留样式
6. 浏览器控制台无报错；宿主侧无新增接口
